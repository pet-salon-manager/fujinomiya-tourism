# 富士宮たびナビ
静岡県富士宮市に特化した観光案内PWAの試作版です。

## 入っている機能
- 観光地・自然・体験・グルメ・学び・登山のカテゴリ検索
- キーワード検索
- お気に入り保存（端末内）
- Google Mapsで地図表示
- 現在地から目的地へのルート起動
- モデルコース
- ホーム画面追加に対応するPWA構成

## 起動
ローカルではHTTPサーバー経由で開いてください。
例: `python3 -m http.server 8000`
その後 `http://localhost:8000` を開きます。

## 公開前に追加推奨
- 公式情報で住所・営業時間・料金・定休日を検証
- 実写写真
- 飲食店・宿泊施設・温泉・キャンプ場データの拡充
- 現在地からの距離順ソート
- 富士宮市公式観光情報への導線
- 管理画面・クラウドDB
